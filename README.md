# 云上清凉寺

公开页面：https://luoshengqi588-jpg.github.io/yunshang-qingliangsi/

原生单页 `index.html`，通过现有 GitHub Pages 发布；无需构建或新增服务。Firebase Realtime Database 保持共享许愿墙和真实访客统计，功德簿仍存在本机。离线时继续使用现有的本机提示与回退逻辑。

## 礼佛动画

原视频被站内 SVG 分关节动画替换，无第三方动画库、视频请求或付费服务。采用约六岁小沙弥的侧面插画，便于看清额头和蒲团的接触；全身、双手和脚始终在画面内。

点击「礼佛」开始，9 秒一拜，共 27 秒：静心合十 1 秒、分手扶蒲团 1 秒、俯身 2 秒、触额停顿 1.2 秒、起身 2.2 秒、合十 1 秒、静候 0.6 秒。双手先落定，再俯身；起身后才重新合十。额头接触点为 SVG 坐标 (220,229)，对应蒲团上表面。三次触额各响一声磬。

动画只在用户点击后播放。后台暂停，回到前台接续；长时间卡顿不会跳过动作。可随时停止，只有完整三拜结束才记录一次功德。动画随容器缩放，未增加视频加载体积。

## 本地检查

```sh
python -m http.server 8000
node --test tests/bow.test.cjs
```

用浏览器打开 http://localhost:8000/ 。测试只依赖 Node.js 内置模块，覆盖三次停顿、触额几何位置、停止与重播计数、后台暂停。仓库原先没有构建、lint 或自动测试配置。

发布前还应在手机尺寸查看合十、扶蒲团、触额和起身，并确认共享模式、数据库访客数和已有心愿正常。测试线上 Firebase 时，避免提交无意义的测试心愿。浏览器模拟手机尺寸不等同于真实 iOS/Android 设备验证。
